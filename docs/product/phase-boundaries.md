# 阶段边界

## Phase 1：服务交易与交付

范围包含官网内容、身份账户、活动、课程、真人辅导、AI 辅导入口、统一目录、订单、支付与运营后台。完成标志是真实用户可注册、购买服务并获得交付记录；支付权益只能由经验证且幂等的服务端事件开通。

## Phase 2：婚恋匹配闭环

范围包含婚恋档案、择偶条件、筛选推荐、喜欢、互选、认识邀请、关系状态、会员权限与安全审核。完成标志是真实用户可在审核与隐私政策保护下建档、查看可解释推荐、表达选择并进入认识期。

## 明确不跨越的边界

- Batch 1 不创建虚假的身份、支付、AI 或匹配业务实现。
- Phase 1 不擅自引入 Phase 2 的联系方式交换或关系状态政策。
- AI 建议不替代支付、权限、风险处置或关系状态的后端规则。
- 未经授权的资料不进入 AI 知识库。
- `undecided` 的产品事项仅以关闭功能或显式配置缺失的形式存在，不设隐含生产默认值。
