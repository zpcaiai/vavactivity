# Block propagation failure

## Symptoms and impact

Any route still connects a blocked pair, creating an immediate safety and privacy risk.

## Detect and contain

Run both participant directions through profile, recommendation, invitation, contact, messaging, and relationship routes. Apply the synchronous central deny, freeze shared artifacts, preserve reporter confidentiality, and escalate as critical.

## Recover and verify

Repair/replay the idempotent block propagation, pair exclusions, recommendation/invitation invalidation, contact revocation, and journey freeze. The complete matrix and red-team bypass rate must be zero before constraints are lifted.

## Rollback, communication, and review

If the repair regresses, disable the affected interaction surfaces while keeping safety access available. Use non-shaming user communication and review every authorization path and propagation SLO.
