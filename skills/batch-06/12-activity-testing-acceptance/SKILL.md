# Acceptance

Run unit and integration tests, then real concurrent last-seat, promotion and
reciprocal-choice tests. Test private location, meeting URL, cross-user form,
QR tampering, directory eligibility and one-sided-choice privacy. Run user and
admin browser journeys, `make activity-verify`, then the Batch 1–5 regression.
Unrun external evidence stays explicitly unverified.
