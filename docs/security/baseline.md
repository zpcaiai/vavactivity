# Batch 1 安全基线

## 凭据与配置

- `.env` 被 Git 忽略，`.env.example` 只含明确标记的本地开发值。
- 生产环境配置会拒绝本地数据库地址或开发密码。
- 公开系统配置端点只返回环境、版本、展示时区和功能开关。
- CI 对完整 Git 历史运行 Gitleaks。

## 权限

运营端的路由元数据和 `v-permission` 只改善界面体验，不构成授权。开发预览仅在 Vite 开发模式可用；生产构建未认证时必须返回登录入口。Batch 2 的每个运营 API 都必须在后端检查身份、角色、权限和资源范围。

## 数据与审计

- PostgreSQL 不应在生产环境暴露公网。
- MinIO 初始化桶保持匿名访问关闭。
- `audit_events` 通过触发器拒绝更新和删除。
- Request ID 可以跨日志、任务和后续审计事件关联。
- 日志不得包含访问令牌、密码、连接字符串、私人联系方式或支付信息。

## 未决业务政策

任何 `undecided` 项都必须保持关闭。尤其禁止在收款主体、联系方式交换和 AI 知识授权未确认时开放对应能力。
