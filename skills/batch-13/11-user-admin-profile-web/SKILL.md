# Member and administrator surfaces

The member journey is a ten-step stepper with save-and-exit, backend-reported completeness,
missing-field prompts, per-context preview, submission, review feedback, pause and reactivate.
The administrator review center provides the queue, version diff, field and photo decisions,
suspension with reason codes, schema/taxonomy registries, projection rebuilds and the audit trail —
with contact details, AI transcripts, counseling records and payment data excluded by design.
