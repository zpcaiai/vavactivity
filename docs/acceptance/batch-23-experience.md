# Batch 23 acceptance boundary

Automated technical evidence is generated by `make experience-evidence-build` and is checksum-bound to the current Git commit and manifests. Backend, frontend, migration and browser results must be reported from commands actually run.

Role-based UAT, support review and production observation are external evidence. They remain `NOT_RUN` until performed by their named owners. Therefore production status remains `NOT_CERTIFIED` and `release_allowed=false` even when local technical gates pass.
