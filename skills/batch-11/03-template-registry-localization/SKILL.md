# Template registry and localization

Provide strict JSON-like variable schemas and immutable releases for zh-CN, zh-TW and en.
Escape user values and reject scripts, executable expressions, forms, event handlers, unsafe
protocols, undeclared variables and releases that are not approved before activation.
