# Process recovery runbook

1. Inspect the instance timeline and authoritative domain receipt.
2. Confirm the expected event gap, retry limit or SLA breach.
3. Use an allowed registered recovery command only.
4. Recheck authorization, privacy and safety restrictions.
5. Verify the command receipt and domain postcondition.
6. Resolve the finding; never edit a business state directly.

Production certification remains `NOT_CERTIFIED` until independent, environment-bound evidence covers every required path.
