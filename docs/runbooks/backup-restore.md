# 备份与恢复基线

Batch 1 只定义可复现步骤；生产存储位置、保留期和加密密钥必须在部署决策中确认。

## PostgreSQL

备份应使用与 PostgreSQL 16 兼容的 `pg_dump --format=custom`，恢复演练使用隔离数据库和 `pg_restore --clean --if-exists`。每次正式发布前必须确认最新备份可读，定期恢复演练需记录耗时、迁移版本和抽样数据校验。

## MinIO

对象备份必须保留私有访问属性、对象元数据与版本信息。不得只备份数据库中的对象键。恢复演练应核对对象数量、总字节、抽样校验和及授权策略。

## Redis

Redis 不作为业务事实来源。Celery 任务必须幂等，缓存丢失不得导致订单、权益或关系状态丢失。需要长期留存的结果必须进入 PostgreSQL。
