# Rules

- Member UI explains mutual stages, unilateral pause/end, mutual resume and private reflection.
- Destructive/member-state actions require explicit confirmation and surface stale-state errors.
- Routine admin UI is pseudonymous and excludes private content.
- Admin UI exposes safety controls by permission but never member acceptance, confirmation or restore.
- Both interfaces state that the platform does not score relationship health.

# Verify

Run component/route tests, accessibility checks and both browser journeys with real authenticated fixtures.
