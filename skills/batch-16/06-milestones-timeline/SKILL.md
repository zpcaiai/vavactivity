# Rules

- Only the author edits/deletes a milestone; a partner sees shared entries only.
- Encrypt descriptions and expose verified system milestones only from trusted source events.
- Timeline contains state transitions and controlled metadata, never private descriptions/reasons.
- Deletion is a status transition, not destructive history removal.

# Verify

Test author ownership, private visibility, encrypted storage, optimistic version and safe timeline projection.
