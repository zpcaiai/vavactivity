# VAV 项目范围

VAV 是一个前后端分离、以模块化单体为起点的婚恋智能服务平台。交付物包含面向用户的 Web 应用、独立运营管理端、FastAPI 后端、Celery 异步任务、PostgreSQL 数据库及可复现的本地基础设施。

## 产品目标

第一阶段建立“了解服务—注册—购买—参加活动/课程/辅导—获得通知”的可用闭环。第二阶段在安全审核和会员权限保护下建立“建档—推荐—表达选择—互选—邀请认识—关系状态记录”的闭环。

## 本批范围

Batch 1 只交付可运行、可测试、可扩展的工程基座：

- 用户端和运营端的页面、导航、国际化和权限接口骨架；
- 带标准响应、请求追踪、日志、数据库和 Redis 就绪检查的 API；
- PostgreSQL、pgvector、Redis、MinIO、Mailpit 和 Celery；
- Alembic 迁移、OpenAPI 契约及生成的 TypeScript SDK；
- 本地启动脚本、CI 质量门禁和新开发者验收脚本。

本批不实现注册、支付、推荐或 AI 对话业务，也不为待决策事项选择生产政策。

## 范围控制

`project-manifest.yaml` 是阶段、模块、负责人、状态和待决策项的机器可读来源。新增业务能力必须同时更新需求追踪和验收映射。任何涉及收款主体、首发地区、语言优先级、会员方案、联系方式交换或知识授权的实现，都必须等待决策登记状态变为 `decided`。
