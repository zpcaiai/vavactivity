# Component Inventory

Foundation components cover buttons, status, alerts, field association, error summary, live regions, skip links, page states and focus-managed modal dialogs. `@vav/ui-user` supplies reading/form layouts and safe-area action bars. `@vav/ui-admin` supplies responsive data tables, filter panels, timelines and independent review workbenches.

Each component has a package owner, source location, accessibility contract and supported-state list in `ui_components`. Deprecation is explicit and audited; active consumers receive a replacement code and reason. Storybook uses synthetic fixtures only.
