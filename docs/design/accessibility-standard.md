# Accessibility Standard

The target is WCAG 2.2 AA for governed components and critical pages. Required controls include semantic landmarks, keyboard reachability, visible focus, modal focus trapping/restoration, 44px targets, programmatic labels, field descriptions, live state announcements, text-equivalent status, reduced motion and high-contrast theme support.

Automated axe checks are blocker evidence for serious and critical findings, but cannot certify assistive-technology behavior. Accessibility audit records therefore remain `technical_pass` or `needs_review` until an independent reviewer accepts checksum-bound keyboard and assistive-technology evidence.
