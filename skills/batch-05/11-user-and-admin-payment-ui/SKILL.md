# Workflow

Show server-calculated amounts, currency, discounts, tax uncertainty, inventory
expiry, Provider, refund-policy version and renewal notice. After Provider
return, show confirmation in progress and poll the backend; ignore success query
parameters. In administration, redact Webhook payloads and require reasons for
refund approval/submission, entitlement revocation, replay and reconciliation
resolution.
