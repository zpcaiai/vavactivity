# Member and operator surfaces

The member page shows today's batch, an honest empty state, recommendation settings, their own
history and a transparency view. A card carries a de-identified summary, template explanations
and the standing caveat — never a percentage, a score or contact details. Exposure is reported
from real visibility, not from render. The operator centre exposes the pool, batches, strategy
versions with approve / activate / rollback, the feature manifest, hard-constraint policy,
exposure and feedback statistics, offline evaluations, experiments, aggregate user diagnostics
and the audit trail. Every section is permission-gated, and diagnostics name no candidate.
