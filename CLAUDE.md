# Claude Code project instructions

The canonical shared task ledger for Claude Code and Codex is
`.ai/TASK_PROGRESS.md`.

Before changing the repository, read that document and reconcile it with the
current Git state. Update it at meaningful milestones, handoffs, and blockers.
Before reporting a task as complete, write the result, validation evidence,
commit/push state, and any remaining evidence gaps back to the document. Do not
overwrite concurrent work or claim external/production gates without evidence.
