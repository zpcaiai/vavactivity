# ADR-0001：采用前后端分离的模块化单体

- 状态：已接受
- 日期：2026-07-31

## 背景

平台需要同时支持公开内容、交易交付、婚恋匹配、安全审核和 AI 辅导。团队需要在早期保持部署和数据一致性简单，同时避免业务模块、AI 能力和用户界面相互耦合。

## 决策

后端采用 FastAPI 模块化单体，模块通过明确的应用服务和持久化边界协作；用户端和运营端为两个独立 Vue 应用；异步工作由 Celery 承担；PostgreSQL 是事务数据来源。OpenAPI 是前端 DTO 的唯一来源。

AI 作为可关闭的外围模块，故障不得影响账户、订单、支付或安全审核。权限和支付确认始终以服务端规则为准。数据库结构只通过 Alembic 变更。

## 结果

早期只有一个业务后端需要一致部署，事务与审计更容易保证。模块边界为未来按容量或合规需要拆分服务保留路径。代价是必须持续执行模块依赖纪律，并防止共享数据库演变为任意跨模块访问。
