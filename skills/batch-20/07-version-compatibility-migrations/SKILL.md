description: Implement Skill SemVer compatibility, deprecation, permission diffs, state migrations, dry-run upgrades, canaries, rollback, or downgrade safety.
---

Active versions are immutable. Breaking schema or behavioral changes require a major version; permission expansion requires renewed approval. Migrations are explicit and idempotent. Incompatible upgrades remain inactive and the prior version stays available.
