# Workflow

Persist the random seed and sorted participant input. Prevent one active
assignment per plan. Reject silent regeneration of locked plans. Audit manual
moves. Never use sensitive or protected registration fields without an approved,
disclosed rule. Users see only their own group and public member fields.
