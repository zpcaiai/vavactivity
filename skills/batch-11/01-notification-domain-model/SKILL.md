# Notification domain model

Create versioned events, intents, in-app notifications, deliveries, attempts, preferences,
consents, reminders, digests, campaigns, provider events, suppressions, dead letters and audit.
Use database uniqueness for every specified idempotency boundary and encrypt sensitive content.
